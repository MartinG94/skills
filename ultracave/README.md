# Ultracave — Compresión Extrema y Despojo Gramatical

Variante de máxima compresión de Caveman para agentes de IA. Despoja la estructura gramatical tradicional dejando únicamente fragmentos telegráficos esenciales y la carga técnica intacta.

## Características

- **Compresión Máxima**: Hasta un 35% de ahorro adicional frente al modo conciso convencional.
- **Sintaxis de Fragmentos**: Supresión completa de artículos, cópulas y conectores.
- **Una Palabra Cuando Basta**: Respuestas binarias o atómicas cuando la pregunta lo permite.
- **Payload 100% Intacto**: Comandos, código, rutas y negaciones no sufren alteraciones.

## Activación

- Invocación: `/ultracave` o `/caveman ultra`
- Desactivación: `stop caveman` o `normal mode`
