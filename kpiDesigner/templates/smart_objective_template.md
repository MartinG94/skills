# Plantilla y Reglas de Formulación de Objetivos SMART

## 1. Fórmula Canónica de Sintaxis SMART

Todo objetivo cuantitativo debe cumplir rigurosamente con la siguiente estructura:

$$[\text{Verbo de Acción en Infinitivo}] + [\text{Variable o Métrica}] + [\text{de Línea Base a Meta}] + [\text{Plazo o Fecha Límite}]$$

### Ejemplos Validados por Dominio

1. **Operaciones / Procesos:**
   > *"Reducir el tiempo promedio de despacho de pedidos de 48 horas a 4 horas para el 31 de diciembre de 2026."*
2. **Calidad / Lean:**
   > *"Disminuir el porcentaje de merma de productos perecederos de 6.5% a menos de 1.0% en 6 meses."*
3. **Negocio / Estrategia:**
   > *"Incrementar el nivel de cumplimiento de entregas a tiempo (OTIF) de 78% a 95% para el cierre del Q4."*
4. **Software / DevOps:**
   > *"Acortar el Lead Time for Changes de 72 horas a 30 minutos antes de octubre de 2026."*
5. **Producto / UX:**
   > *"Aumentar la tasa de retención mensual de usuarios activos de 42% a 68% durante el primer semestre de 2027."*

## 2. Checklist de Validación SMART

| Criterio | Pregunta de Control | Verificación |
|---|---|---|
| **S (Specific)** | ¿Está claro qué proceso, variable o comportamiento exacto se está interviniendo? | Sí / No |
| **M (Measurable)** | ¿Existe una unidad de medida explícita y una fórmula de cálculo no ambigua? | Sí / No |
| **A (Achievable)** | ¿La meta es realista considerando los recursos, tecnologías y restricciones del proyecto? | Sí / No |
| **R (Relevant)** | ¿El objetivo responde a una Acción de Valor del CAME o a una directiva estratégica de la empresa? | Sí / No |
| **T (Time-bound)** | ¿Tiene una fecha límite, trimestre o ventana temporal explícita para la evaluación? | Sí / No |
